# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work.
Harassment and personal attacks are not tolerated.

## Reporting

Contact the maintainer privately through their GitHub profile,
[github.com/peppe-git](https://github.com/peppe-git). There is no e-mail contact. Reports are handled
confidentially.

The maintainer may remove content, or restrict participation, when that is needed to keep the project
welcoming.

Security vulnerabilities follow [SECURITY.md](SECURITY.md) instead.
